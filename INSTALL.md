# Installation status

**The public installer is not available yet.** Nova is Alpha / preparing for outside testing.

This page will receive installation instructions when a specific artifact is authorized for the
relevant testing stage.

Each downloadable candidate will identify:

- its version and exact source revision;
- the installer filename and SHA-256 checksum;
- tested Windows versions and measured hardware requirements;
- required model downloads, configuration, and external-provider use;
- installation, startup, removal, and retained-data behavior;
- known limitations and the applicable technical-validation or product-testing procedure.

Hardware requirements have not been established by this overview. No minimum RAM figure or
clean-machine success is claimed here.
